# Security policy

Archimet is still a local release candidate. Do not expose its gateway to the public internet. Read the [security model](docs/SECURITY.md) and [release status](docs/STATUS.md) before deployment.

Please report a suspected vulnerability **privately** to the repository owner. Once a public GitHub repository exists, use its private vulnerability reporting option if enabled; otherwise contact the maintainer through a private channel listed in the repository profile. Do not post credentials, private keys, real device data, or exploit details in a public issue. The maintainer will acknowledge, reproduce, fix and publish guidance after assessing the report. No response-time guarantee is claimed yet.

Security updates for the pinned Kismet engine are **not automatic**. A new upstream engine release must be tested with Archimet and deliberately released by the owner. The current tested versions and exceptions are in [updates](docs/UPDATES.md).
